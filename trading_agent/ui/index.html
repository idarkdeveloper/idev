Kill switch

loading…

Stops all trading at once: writes state/HALT, stops the watch, cancels the agent's open orders at Groww, deletes the saved Groww token and alerts you by Telegram and email. GTT stop-losses stay (they keep protecting your holdings) unless you tick the box. Only python -m trading_agent kill-switch --release on the server undoes it.

    Screener
    
      
    Off by default. Turning it on lets the screener ask TradingView's public scanner for a few extra columns (its summary, sector, industry, EPS growth). TradingView has no official API for this and its terms restrict automated access, so you are choosing to use an unofficial endpoint. One request per list, at most every 15 minutes; if it ever refuses or fails it is left alone for 24 hours. No login, no cookies. Display only: it never feeds the agent, the emails or Claude, and it is never called from the server.
    
    
    
    
    Live checks
    
      
    Reads NSE, BSE, Yahoo, NSE's archive files and, with a login token Groww already gave out, your holdings and order list. It never places an order and never asks Groww for a new token. A failure sends one alert a day. Takes effect when the watch service restarts.
    
        
    A five-token "Reply OK" to Claude Haiku: costs a fraction of a paisa, off by default.
